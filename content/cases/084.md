Every measurable set of positive length contains a translated, scaled copy of any finite pattern of real points. Infinity changes the question. In his [1974 congress problem list](https://users.renyi.hu/~p_erdos/1974-27.pdf), Paul Erdős asked whether every infinite set could instead be excluded from some positive-measure set.

Falconer and Eigen settled slowly decreasing sequences in 1984–1985. But the apparently simple pattern ½, ¼, ⅛, … falls outside their hypothesis: each step shrinks by a fixed ratio. Bourgain developed an additive route, while [Kolountzakis’s probabilistic work](https://eigen-space.org/mk/ps/universal.pdf) blocked almost every placement. Neither statement automatically blocks every copy of one geometric sequence.

A later branch sharpened the distinction. [Feng, Lai and Xiong](https://arxiv.org/html/2312.01319v1) showed that geometric sequences fit every positive-measure set if controlled distortion is allowed. A similarity, however, must use one translation and one scale for all terms.

The 2026 OpenAI collection reports avoidance for every fixed geometric ratio, with compact sets occupying arbitrarily nearly the whole unit interval. The avoiding set may depend on the ratio. This is a reported special case of Erdős’s broader question, not an independently verified solution of the full conjecture.
